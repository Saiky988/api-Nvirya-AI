# Nvirya AI — API Documentation

Nvirya AI provides an OpenAI-compatible API augmented with an internal server-side agent runtime, model routing, tool calling, web search/fetch, artifact storage, and quota enforcement.

Base URL: `http://localhost:8000/v1` (or your deployment domain)

---

## 1. Authentication

All protected endpoints require an API key passed in either the `Authorization` header as a Bearer token or via the `x-api-key` header:

```http
Authorization: Bearer nv-xxxxxxxxxxxxxxxxxxxxxxxx
```
or
```http
x-api-key: nv-xxxxxxxxxxxxxxxxxxxxxxxx
```

API keys are generated via `POST /v1/api-keys`. The plaintext key is only returned once upon creation and hashed securely via SHA-256 in the database.

## 3. Chat Completions

### `POST /v1/chat/completions`

Accepts OpenAI standard payload format.

#### Request Headers
* `Authorization: Bearer <API_KEY>`
* `Content-Type: application/json`
* `X-Request-ID: <OPTIONAL_CORRELATION_ID>`

#### Request Body
```json
{
  "model": "nvirya-auto",
  "messages": [
    {
      "role": "user",
      "content": "Calculate 345 * 28 and write the result."
    }
  ],
  "temperature": 0.7,
  "stream": false
}
```

#### Non-Streaming Response
```json
{
  "id": "chatcmpl-...",
  "object": "chat.completion",
  "created": 1791192195,
  "model": "nvirya-auto",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "345 multiplied by 28 is 9,660."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 42,
    "completion_tokens": 18,
    "total_tokens": 60
  }
}
```

#### Streaming Response (`stream: true`)
Server-Sent Events (SSE) stream:
```text
data: {"id":"chatcmpl-...","object":"chat.completion.chunk","created":1791192195,"model":"nvirya-auto","choices":[{"index":0,"delta":{"role":"assistant"},"finish_reason":null}]}

data: {"id":"chatcmpl-...","object":"chat.completion.chunk","created":1791192195,"model":"nvirya-auto","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}]}

data: {"id":"chatcmpl-...","object":"chat.completion.chunk","created":1791192195,"model":"nvirya-auto","choices":[{"index":0,"delta":{},"finish_reason":"stop"}]}

data: [DONE]
```

## 4. Asynchronous Tasks

### `POST /v1/tasks`
Creates a managed agent task.

```json
{
  "model": "nvirya-auto",
  "messages": [
    {
      "role": "user",
      "content": "Find information about FastAPI and generate a markdown summary."
    }
  ]
}
```

#### Response
```json
{
  "id": "task_4821a81bc7d2903e",
  "object": "task",
  "model": "nvirya-auto",
  "status": "running",
  "current_step": 0,
  "created_at": "2026-10-05T09:30:00Z"
}
```

### `GET /v1/tasks/{task_id}`
Returns current task state and output.

### `GET /v1/tasks/{task_id}/events`
SSE stream emitting lifecycle events:
* `task.created`
* `task.started`
* `model.requested`
* `tool.started`
* `tool.completed`
* `artifact.created`
* `task.completed`

### `POST /v1/tasks/{task_id}/cancel`
Cancels an ongoing task.

## 5. Artifacts

### `GET /v1/artifacts/{artifact_id}`
Downloads or reads a file generated by `file_create`. Requires key belonging to the owner user.

## 6. Usage & Quotas

### `GET /v1/quota`
Returns remaining daily task quota and rate limit.
```json
{
  "daily_limit": 30,
  "daily_used": 4,
  "daily_remaining": 26,
  "rate_limit_per_minute": 1
}
```

### `GET /v1/usage`
Returns token and tool consumption summary:
```json
{
  "user_id": "usr_admin",
  "total_requests": 14,
  "total_prompt_tokens": 1250,
  "total_completion_tokens": 3410,
  "total_tokens": 4660,
  "total_tool_calls": 5
}
```

## 7. Python Client Example

Using the official `openai` Python SDK:

```python
from openai import OpenAI

client = OpenAI(
    api_key="nv-58756a151e46c3cb5d343ba26a9f0be0905300cfddec77b1",
    base_url="http://localhost:8000/v1",
)

# Standard completion with automatic tool execution
response = client.chat.completions.create(
    model="nvirya-auto",
    messages=[
        {"role": "user", "content": "What is 42 * 98? Use calculator."}
    ],
)

print(response.choices[0].message.content)
```
